# REST API 接口设计（v0.1）

> 基础路径：`/api` ｜ 认证：登录后携带 `Authorization: Bearer <JWT>`
> 统一响应：`{ "code": 0, "message": "ok", "data": ... }`（code≠0 表示业务错误）

## 1. 认证

| 方法 | 路径 | 说明 | 角色 |
|------|------|------|------|
| POST | /auth/login | 学号/工号+密码登录，返回 JWT 与用户信息（密码 BCrypt 校验） | 公开 |
| POST | /auth/logout | 退出登录 | 登录用户 |
| GET | /auth/me | 当前用户信息 | 登录用户 |

## 2. 公开信息（F1）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /stages | 8 阶段时间轴与当前阶段（服务器时间判定） |
| GET | /notices | 通知公告列表 |
| GET | /labs | 实训室列表（含名额、已报名人数） |
| GET | /labs/{id} | 实训室详情（导师、培养安排、考核要求、开放日） |

## 3. 学生端（F2/F4/F5/F7）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /student/application?round= | 查询本人某轮意向 |
| PUT | /student/application | 提交/修改意向（≤3 个平行志愿 + 两项调剂意愿；窗口外返回错误） |
| GET | /student/status | 本人选拔状态、当前阶段、截止时间 |
| GET | /student/offers | 本人拟录取意向列表 |
| POST | /student/offers/{labId}/confirm | 确认唯一去向（事务+锁防超录；其余意向置为放弃） |
| GET | /student/result | 最终去向 |
| GET | /publicity | 公示名单（公示期内可见） |
| GET | /notifications | 站内通知列表 |

## 4. 导师端（F3，仅本实训室）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /teacher/applicants?round= | 本室报名学生（含意向与调剂意愿；未满额也全部列出） |
| PUT | /teacher/scores/{studentId} | 录入/修改面试评价（四维度 1–5 分 + 评语） |
| GET | /teacher/lists | 本室三份名单 |
| PUT | /teacher/lists | 提交拟录取/递补（含顺位）/内部调剂候选名单（拟录取≤名额；触发发意向，单意向自动确认） |

## 5. 管理员端（F5/F6/F7/F8）

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | /admin/stages/{id} | 配置阶段起止时间 |
| GET | /admin/quotas | 各室名额/报名/录取/剩余总览 |
| POST | /admin/rounds | 开启第 2/3 轮补录（校验上一轮已完成） |
| POST | /admin/quotas/publish | 公布剩余名额（触发通知） |
| GET | /admin/adjust/pool | 调剂池：剩余名额 + 待安置学生 |
| POST | /admin/adjust/internal | ① 内部调剂安排 |
| POST | /admin/adjust/cross | ② 跨室调剂安排（校验学生服从 + ①已完成） |
| POST | /admin/adjust/talk | ③ 约谈安置（含约谈记录；校验①②已完成） |
| GET | /admin/adjust/logs | 调剂操作留痕 |
| POST | /admin/publicity/publish | 发布公示（公示期 1 天） |
| POST | /admin/publicity/objections | 标记异议 |
| POST | /admin/publicity/end | 结束公示 → 正式入组（校验无未处理异议） |
| GET | /admin/dashboard | 各阶段人数统计 |

## 6. 通用约定

- 时间字段一律 ISO 8601（`2026-11-02T08:00:00+08:00`），窗口判断只在服务端做；
- 分页参数 `page`/`size`（列表默认 page=1, size=20）；
- 错误码示例：`1001` 未登录、`1003` 无权限、`2001` 不在时间窗口、`2002` 志愿数超限、`2003` 名额已满、`2004` 调剂优先级顺序错误；
- 关键写操作（确认/放弃/调剂/公示）服务端自动写 operation_log。
