# 系统架构设计

> 配套文档：[1.pdr/选拔系统PRD.md](../1.pdr/选拔系统PRD.md) ｜ [4.api/接口设计.md](../4.api/接口设计.md)

## 1. 总体架构

B/S 架构，前后端分离，三层部署：

```
浏览器（学生手机 / 管理端桌面）
        │ HTTPS / JSON
        ▼
┌─────────────────────────┐
│ 前端  Vue 3 + Element Plus │  Vite 构建，静态资源部署
│ （frontend/）             │
└───────────┬─────────────┘
            │ REST API（/api/**）
            ▼
┌─────────────────────────┐
│ 后端  Java 17 + Spring Boot 3 │
│ （backend/）              │
│  controller → service → mapper │
└───────────┬─────────────┘
            │ MyBatis / JDBC
            ▼
┌─────────────────────────┐
│ 数据库  MySQL 8            │
│ （framework/3.database/） │
└─────────────────────────┘
```

## 2. 技术选型

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | Vue 3 + Vue Router + Element Plus | 响应式，学生端适配 375px |
| 后端 | Java 17 + Spring Boot 3 + MyBatis | REST API，Maven 构建 |
| 数据库 | MySQL 8（utf8mb4） | 建表与种子脚本见 3.database |
| 认证 | Spring Security + JWT | 学号/工号 + 密码登录 |
| 密码 | BCrypt 加密存储 | 数据库不存明文密码 |

## 3. 后端分层（backend/src/main/java/com/college/selection/）

| 包 | 职责 |
|----|------|
| controller | 接收 HTTP 请求、参数校验、返回统一 JSON（code/message/data） |
| service | 选拔业务规则：意向校验、自动确认、顺位递补、调剂优先级、公示状态机 |
| mapper | MyBatis 接口，读写 MySQL |
| entity | 与表一一对应的实体类 |
| dto | 请求/响应数据格式，不直接暴露 entity |
| config | Security/JWT 配置、跨域、全局异常处理 |

## 4. 关键设计决策

1. **时间窗口以服务器时间为准**：stage 表存每阶段起止时间，service 层统一判断窗口开放，前端只做展示倒计时，不做放行依据。
2. **状态机驱动**：学生选拔状态（未填报→已填报→面试完成→拟录取→已确认/放弃→补录→调剂→已录取→正式入组）由 service 层集中流转，禁止 controller 直接改状态。
3. **并发防超录**：确认/递补名额时用数据库事务 + 行锁（`SELECT ... FOR UPDATE`）或乐观锁版本号，保证两名学生同时确认同一递补名额不超录。
4. **操作留痕**：确认、放弃、调剂、公示等关键操作写入 operation_log 表（谁、何时、做了什么、前后状态）。
5. **RBAC 权限**：三种角色 STUDENT / TEACHER / ADMIN；导师绑定 lab_id，只能操作本室数据；接口层用注解校验角色。
6. **调剂优先级不可颠倒**：service 层校验上一优先级处理完毕才开放下一优先级操作。

## 5. 前端结构（frontend/src/）

```
main.js / App.vue / style.css
router/        路由 + 角色守卫
store.js       当前为本地模拟状态（接后端后改为调用 API）
mock/data.js   演示数据（接后端后删除）
layouts/       顶部导航布局（按角色显示菜单）
views/
  Home / Labs / LabDetail / Login   公开页
  student/       Apply、MySelection、Result
  teacher/       Applicants、Interview、Lists
  admin/         Stages、Quotas、Adjust、Publicity、Dashboard
```

## 6. 部署

- 开发：前端 `npm run dev`（5173 端口），后端 `mvn spring-boot:run`（8080 端口），Vite 代理 /api → 8080；
- 生产（校园服务器）：前端 `npm run build` 产物交给 Nginx 或 Spring Boot static 目录，后端 jar 直接运行，MySQL 本机安装。
